# Changelog

## 1.0.0

- Desktop VS Code extension for the actual bottom status bar.
- Original Shan Shui drawing engine in an isolated worker.
- New cryptographically sampled random seed per window launch or reload.
- Continuous tile generation, bounded caches, and smooth time-based scrolling.
- Scrolling speed, opacity, frame rate, reduced-motion and focus settings.
- Scoped workbench patch with original-file backup, idempotent repair and restoration.
- Offline operation, no runtime dependencies, no telemetry or external assets.
